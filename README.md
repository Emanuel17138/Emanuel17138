**My part:** forecasting engine and API, Copernicus CDS data pipeline, Telegram bot, ES/EN website.

### 🏪 ConviTEC &nbsp;`🚧 coming soon`
**Algorithms & Data Structures I · Project 2**

Distributed inventory and ordering system for a chain of four convenience stores. Branches sync stock through RabbitMQ, deliveries are routed with Dijkstra over a weighted graph of Costa Rica, and every data structure is built from scratch.
