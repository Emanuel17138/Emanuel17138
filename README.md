### 🛰️ [AguaAlerta](https://github.com/Jyin28/Hefesto)
**NASA Space Apps Challenge**

Educational website that shows how temperature and rainfall have changed in Costa Rica, using NASA POWER, Copernicus ERA5-Land and national streamflow data. Interactive maps, a forecasts page and a Telegram newsletter.

**My part:** forecasting engine and API, Copernicus CDS data pipeline, Telegram bot, ES/EN website.

**Smart crib for a client**

**My part:** requirements, Jira backlog and integrating the web base.

### 🎲 [Distributed Monopoly](https://github.com/5amz/Monopoly)
**Algorithms & Data Structures I**

Video-game-themed Monopoly with a client-server architecture over TCP sockets, hand-built linear data structures, and a physical module with RFID cards and an electronic die (Arduino Uno / Raspberry Pi Pico 2 W).

**My part:** desktop client (Windows Forms), TCP protocol and GUI.

### 🏪 ConviTEC &nbsp;`🚧 coming soon`
**Algorithms & Data Structures I · Project 2**

<img src="assets/eye.jpg" width="100%" alt="ConviTEC"/>

Distributed inventory and ordering system for a chain of four convenience stores. Branches sync stock through RabbitMQ, deliveries are routed with Dijkstra over a weighted graph of Costa Rica, and every data structure is built from scratch.
